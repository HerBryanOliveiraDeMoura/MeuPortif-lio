# 💻 Meu Portfólio Pessoal

## 📌 Descrição
Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar meu perfil, conhecimentos e projetos desenvolvidos durante minha formação em Desenvolvimento de Sistemas.

## 🎯 Objetivo
Criar uma página web para apresentar minhas habilidades e trabalhos de forma organizada e acessível.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5

## ⚙️ Funcionamento
O site possui um menu de navegação que permite acessar diferentes seções:

- **Perfil:** apresentação pessoal e conhecimentos.
- **Projetos:** apresentação de projetos desenvolvidos.
- **Contato:** informações para contato.
- **Carousel:** área de destaque com mensagens sobre minha formação.

## ✨ Recurso adicional
Foi adicionado um efeito de animação nos cards dos projetos utilizando CSS.

Ao passar o mouse sobre um card, ele se movimenta para cima e recebe uma sombra, melhorando a interação visual do site.

## 📥 Entrada
Acesso do usuário por meio do navegador e interação com os elementos da página.

## ⚙️ Processamento
O HTML organiza o conteúdo, o CSS personaliza a aparência e o Bootstrap auxilia na estrutura e responsividade do site.

## 📤 Saída
Exibição de um portfólio pessoal com informações, projetos e formas de contato.
